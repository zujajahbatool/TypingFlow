# TypingFlow AI

A VS Code extension for analyzing typing patterns and providing AI-powered typing flow insights.

## Features

- Real-time typing pattern analysis
- Performance metrics and statistics
- User archetype classification
- Typing benchmarks and comparisons
- Visual analytics dashboard

## Requirements

- VS Code 1.85.0 or higher
- Node.js 18.0 or higher

## Extension Settings

This extension contributes the following settings:

* `typingflow.enabled`: Enable/disable the TypingFlow AI extension.
* `typingflow.analytics`: Enable/disable analytics collection.

## Known Issues

- Initial data collection may take a few moments on first use.
